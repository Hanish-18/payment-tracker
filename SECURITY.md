
# Security Policy

## Supported Versions

Only the latest version of Payment Tracker is currently supported.

## Reporting a Vulnerability

If you discover a security vulnerability, please do not disclose it publicly.

Report it privately to the repository owner through a trusted private communication channel.

Include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Relevant screenshots or proof of concept

## Responsible Disclosure

Please allow the repository owner reasonable time to investigate and resolve reported vulnerabilities before public disclosure.

## Security Best Practices

- Never share API keys or passwords.
- Never commit environment files.
- Do not access another user's data without authorization.
- Report suspected unauthorized access immediately.
